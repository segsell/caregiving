# Comparison: Working-share plots (matched differences vs publication)

## Two sources

1. **Matched-differences plot**
   `bld/plots/counterfactual/full_caregiving_leave_with_job_retention/vs_baseline/age_profiles/all/all/age_profiles_work_by_age.png`
   Generated by: `task_plot_matched_differences_by_age_full_caregiving_leave_vs_baseline` in
   `src/caregiving/counterfactual/matched_differences/task_plot_age_profiles_full_caregiving_leave_vs_baseline.py`.

2. **Publication plot**
   Generated by: `task_working_share_by_age_full_normal_leave_vs_baseline` in
   `src/caregiving/tables/publication/task_government_budget_normal_leave_vs_baseline.py`
   (levels: full / normal / baseline; difference: full − baseline, normal − baseline).

They are **not** the same. Below is a systematic comparison.

---

## 1. Definition of “work”

**Both use the same outcome definition:**

- Work = 1 if `choice in WORK` (PT or FT), else 0.
- Matched: `calculate_outcomes(..., choice_set_type="original")` → `WORK` from `model.shared`.
- Publication: `_share_by_age(..., WORK, ...)` → same set.

So the **variable** that is “working” is identical; the difference is **who** is included and **how** it is aggregated.

---

## 2. Sample / population

| Aspect | Matched-differences task | Publication task |
|--------|--------------------------|-------------------|
| **Dead** | Drops rows with `health == DEAD` in both scenarios (`prepare_dataframes_for_comparison`). | No health filter; dead agent-periods stay in the data. |
| **Ever care demand** | Default `ever_care_demand=True` → keeps only agents who **ever** have `care_demand > 0`. | No care-demand filter; all agents. |
| **Ever caregivers** | Default `ever_caregivers=False`; if True, would restrict to ever informal caregivers. | Optional `only_caregivers=False`; if True, restricts to **current** caregivers (choice in INFORMAL_CARE) only. |
| **Matching** | **Same (agent, period)** in both scenarios: inner merge on `(agent, period, age)`. Only agent-periods that exist in **both** full leave and baseline. | **No matching.** Full leave and baseline are aggregated **separately**; the set of agent-periods at each age can differ between scenarios. |

So:

- **Matched:** Restricts to alive + (by default) ever care-demand agents, then only (agent, period) present in both runs.
- **Publication:** All agent-periods in each run (or only current caregivers if `only_caregivers=True`), no alignment between runs.

---

## 3. Aggregation by age

**Matched-differences:**

- After merge: for each (agent, period) we have `work_o` (full leave) and `work_c` (baseline).
- `diff_work = work_o - work_c` (difference for the **same** agent and period).
- Then: **mean(diff_work) by age** → one number per age.
- So: *“Among matched (agent, period), average change in work (full − baseline) at each age.”*

**Publication:**

- Full scenario: over **all** agent-periods in the full-leave data, **mean(work) by age** → share working at each age in the full world.
- Baseline: same for baseline data.
- Difference plot: **mean(work)_full − mean(work)_baseline** by age (no matching).
- So: *“Difference between the share working at age a in the full-leave world and the share working at age a in the baseline world.”*

---

## 4. What each plot shows

**Matched-differences (`age_profiles_work_by_age.png`):**

- **Y-axis:** Average **difference** in work (full leave − baseline) at each age.
- **Population:** Alive, (by default) ever care-demand agents; only (agent, period) that appear in **both** scenarios.
- **Interpretation:** For the **same** agent-periods, how much higher/lower is the probability of working in the full-leave scenario than in the baseline. Closer to a **causal** comparison (same units, same period).

**Publication (levels + difference):**

- **Levels:** Three lines = share working by age in full leave, normal leave, and baseline (each over its **own** agent-periods).
- **Difference:** Two lines = (share full − share baseline) and (share normal − share baseline) by age.
- **Population:** All agent-periods in each scenario (or only current caregivers if `only_caregivers=True`); **no** requirement that the same agents or periods appear in both scenarios.
- **Interpretation:** Difference in **population** working shares at each age; composition (who is at that age, survival, etc.) can differ between scenarios.

---

## 5. Why the curves can differ

1. **Different populations**
   - Matched: ever care-demand, alive, and only (agent, period) in both runs.
   - Publication: all (or current caregivers), no matching, possibly including dead.

2. **Composition vs same-unit comparison**
   - Matched: same (agent, period) in both worlds → pure “effect” for those units.
   - Publication: different agent-periods at each age in the two runs (e.g. different survival) → difference in shares mixes **behavior** and **composition**.

3. **Survival**
   - If full leave changes who is still alive at a given age, the publication “share at age a” uses different people in the two scenarios. The matched plot only uses agent-periods that exist in both, so it does not reflect that compositional change.

4. **Single line vs two lines**
   - Matched: one line = mean(matched diff) by age.
   - Publication difference: two lines (full − baseline, normal − baseline). The “full − baseline” line is the one to compare conceptually to the matched line; they still differ because of (1)–(3).

---

## 6. Summary table

| Dimension | Matched-differences (`age_profiles_work_by_age.png`) | Publication (`task_working_share_by_age_...`) |
|----------|------------------------------------------------------|----------------------------------------------|
| Outcome | work = 1 if choice in WORK | Same |
| Sample | Alive; ever care demand; **(agent, period)** in both scenarios | All (or only current caregivers); no matching |
| By age | mean(**diff_work**) over matched (agent, period) | mean(work) **per scenario**, then difference of those means |
| Plot content | One line: mean(full − baseline) by age | Levels: 3 lines; Difference: 2 lines (full−base, normal−base) |
| Same result? | **No** — different sample and different aggregation |

---

## 7. When they would coincide (in theory)

The two would only match if:

1. The **same** (agent, period) set were used in both (as in the matched task), and
2. We computed **mean(work_full) − mean(work_baseline)** by age on that **matched** set.

Then “difference of means” = “mean of differences,” so the publication-style difference (on the matched set) would equal the matched-differences line. In the current code, the publication task does **not** restrict to matched (agent, period) and does **not** drop dead or restrict to ever care demand, so the two plots are not the same.

---

## 8. Recommendation

- **Matched plot:** Use when you want “average change in working for the **same** agent-periods (alive, ever care demand), full leave vs baseline.”
- **Publication plot:** Use when you want “how **population** working shares by age differ between scenarios,” allowing different composition and no matching.

If you want the publication plot to be comparable to the matched one, you would need to:

1. Restrict both scenarios to the **same** (agent, period) (e.g. inner merge on agent, period), and
2. Optionally apply the same filters (alive, ever care demand) as in `prepare_dataframes_for_comparison`, then
3. Compute share working by age in each scenario on that common set and plot the difference.

That would make the “full − baseline” difference line conceptually align with the matched-differences plot (same population and same aggregation logic).
